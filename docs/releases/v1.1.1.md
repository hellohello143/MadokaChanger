## MadokaChanger 1.1.1

Unpublished development notes. These changes are included in the public 1.2.0 release.

Click the sidebar chibi to switch between Madoka and Homura.

### Changed

- The chibi is a little smaller: 144 px normally, 96 px in short layouts and 40 px in compact navigation.
- Clicking Madoka switches to a matching Homura chibi and a purple/grey theme. Click Homura to return to the original pink/plum colors.
- Buttons, panels, menus, borders, highlights and artwork placeholders update together, without changing your current page, search, skin preview, favorites or selections.
- The mascot is also a keyboard-accessible button. The theme choice is saved immediately and remembered after restarting or saving other settings.

### Downloads

- **MadokaChanger-Setup-1.1.1.exe** — the updated Windows x64 installer. Close MadokaChanger before upgrading; existing data is preserved.
- **MadokaChanger-Uninstaller.exe** — the same existing standalone tool for cleaning up old installed/portable copies before installing. It keeps skins/settings unless you explicitly select their deletion, and can also remove the newest version because it matches by name.
- **SHA256SUMS.txt** — checksums for both executables.

### Verification

- Release build passed with zero warnings/errors; all 150 automated tests passed.
- Seventeen off-screen WPF layouts passed, including both palettes, live character switching, responsive mascot sizes, persistence, collection-state preservation and binding checks.
- Isolated installer payload, upgrade, uninstall and data-preservation checks passed.

Both executables are unsigned. Live in-game rendering was not part of this update's verification.
