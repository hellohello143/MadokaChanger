## MadokaChanger 1.0.1

Fixes the administrator prompt on every session and library skins not applying in game.

### Download

Choose **MadokaChanger-Setup-1.0.1.exe** below and run it. It upgrades an existing 1.0.0 install in place; settings and downloaded skins are kept. Close MadokaChanger before upgrading.

### Fixed

- **No more admin prompt on Start.** The patcher is elevated only when League itself runs as administrator, or when **Run patcher as administrator** is turned on in Settings.
- **Skins apply in game.** League's anti-skinhack scan flags official library skins, so it is now relaxed by default (the same hook flag LTK Manager uses when its warning is turned off). **Enforce anti-skinhack scan** in Settings switches it back on.
- **Signed patcher when available.** If LTK Manager is installed, its signed patcher is used automatically. The bundled patcher is the fallback.
- **Fewer false stops.** Warning-level "wad scan failed" lines no longer end the session.
- **Clear status.** The status bar switches to **In game · skins applied** once League actually loads a modded archive.

### Validation

- 59 automated tests pass.
- Isolated installer, payload (854 files), upgrade and uninstall checks pass.

In-game rendering has not been verified for this build yet. If a skin does not show, send the newest log from `%LOCALAPPDATA%\MadokaChanger\logs`. The installer is unsigned; `SHA256SUMS.txt` provides its checksum.
