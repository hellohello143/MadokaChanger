## MadokaChanger 1.0.0

The first public Windows x64 installer, with the backend and .NET runtime included.

### Download

Choose **MadokaChanger-Setup-1.0.0.exe** below. Install it, then open MadokaChanger from the desktop or Start menu. No separate backend selection or LTK installation is needed.

### Included

- Dark Madoka theme and chibi application icon.
- Champion search, favorites, saved selections and custom skin imports.
- Responsive windowed layouts with a preview that stays visible.
- Horizontal skin selection and restored chroma color circles.
- Per-user installation, optional desktop shortcut and standard uninstaller.

### Validation

- 39 automated tests pass.
- Off-screen WPF checks cover small/large windows and 125%/150% render scales.
- Isolated installer, payload, upgrade and uninstall checks pass.

Live game attachment and in-game rendering remain unverified for this build. Compatibility depends on the game patch and bundled backend. The installer is unsigned; `SHA256SUMS.txt` provides its checksum.

Settings and downloaded/imported skins are preserved on uninstall. Skin packages and game artwork are downloaded by the app and are not included in the installer.
