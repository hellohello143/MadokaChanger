## MadokaChanger 1.1.0

Downloaded library packages now use local storage obfuscation while the collection keeps its original names and selections.

### Downloads

- **MadokaChanger-Setup-1.1.0.exe** — the new Windows x64 installer. Close MadokaChanger before upgrading. Existing settings and downloaded libraries are preserved.
- **MadokaChanger-Uninstaller.exe** — the existing standalone tool for removing old installed or portable MadokaChanger copies. Use it before installing the new version if cleanup is needed. It keeps skins and settings unless you explicitly select their deletion. It matches by name and can also remove the new version.
- **SHA256SUMS.txt** — SHA-256 checksums for both executables.

### Changed

- Downloaded packages receive persistent opaque filenames and package name metadata. Original skin names, champion/chroma/form mappings, previews, search, favorites and saved selections remain available in the app.
- Upstream Git blobs and LFS payloads are verified before rewriting. Final local package SHA-256 and byte size are recorded separately.
- Rewritten packages pass validation and payload/override comparisons before the staged generation is activated. Cancellation or failure preserves the previous working library.
- Existing libraries migrate even when the upstream commit has not changed. Current transformed libraries are reused on later launches.
- Fantome, recognized Fantome ZIPs and modpkg v1 are supported. Signed modpkg containers, ambiguous metadata and unsupported formats abort the transaction. modpkg metadata is limited to 16 MB stored/expanded; existing WAD v3 and extraction limits still apply.

This is local storage obfuscation. Package filenames and metadata changes alone do not establish user security or encrypt content. Custom imports retain their existing behavior.

### Verification

- 150 automated tests passed, including native modpkg and transaction/migration coverage.
- Release build passed with zero warnings/errors.
- Off-screen WPF identity, mapping, path resolution, search, skin/chroma selection, layout and binding checks passed.
- Isolated installer payload, upgrade, uninstall and data-preservation checks passed.

Both executables are unsigned. Checksums are attached. Live in-game rendering was not part of this release's verification.
