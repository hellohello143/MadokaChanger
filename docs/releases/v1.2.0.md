## MadokaChanger 1.2.0

Duo Mode lets two people share supported skin selections through a private four-digit party code. Open **Duo**, create a party and have your partner join. The shared HTTPS relay is ready to use.

### Changes

- Detects your current League champion through the local League client and shares your committed skin, chroma and form selection.
- Temporarily combines both players' exact catalog selections without changing saved preferences. Both installations need matching library versions and the exact packages installed.
- Rebuilds an already running patcher at safe points. Changes during a game wait until it closes. Joining a party never starts a stopped patcher.
- Reports connection, partner presence, desired/prepared selections and unavailable packages. Leaving removes the temporary partner selection at the next safe point.
- Includes the smaller sidebar mascot and Madoka/Homura theme switching, with the selected theme remembered.
- Future updates explicitly retain the running installation folder and install silently before reopening MadokaChanger.

### Updating

Existing users can press **Update** in MadokaChanger and accept the new version, or run **MadokaChanger-Setup-1.2.0.exe**. Existing skins, settings, favorites and custom imports are preserved.

Downloads include the Windows x64 setup, the existing standalone old-copy uninstaller and `SHA256SUMS.txt`. The standalone cleanup tool can remove current copies too; it is optional and is not needed for an ordinary update.

### Verification and limits

Release build, automated Core and relay tests, off-screen WPF layout checks, real-relay two-client verification and isolated installer checks passed. The old updater's compatibility with this published release is checked separately after publication; see [update verification](../../verification/UPDATE.md).

Live two-PC in-game rendering has not been verified. Different appearances for two players using the same champion, mid-game hot reload and transfer of imported custom packages are unsupported. Both release executables are unsigned.
